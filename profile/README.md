# preset.nz

A one-person software studio in New Zealand. Desktop tools for image processing, mapping, colour
and sound. Built with agents. The apps and the writing live at **[preset.nz](https://preset.nz)**.

This organisation holds the parts I share: the libraries now, the app source and the apps
themselves as they're ready. Tooling is built as multipliers, each piece a bet that the next app
starts further along. Some bets don't resolve.

**Rhizome.** The studio's full name is rhizomatic preset, after Deleuze and Guattari: no centre, no
top, many ways in and out. Any repo below is an entry point, whether an app, its source or a library
underneath. Start anywhere, follow it anywhere, leave wherever you like.

MIT licensed. There's no support contract and no SLA. We don't ship missing disks.
